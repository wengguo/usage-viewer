# 自助查询页 UI 体验优化 — 设计

## 背景

用户反馈自助查询页（`/self`）体验较差，对比排行榜页（`/leaderboard`）：
1. 页面偏窄、两侧留白过多
2. 结果卡片信息呈现平淡，缺少视觉层次
3. 查询前/无结果时是一片空白，没有引导

## 方案

范围限定在 `internal/web/self.html` 和 `internal/web/self.js`，不改动后端接口、其他页面。`app.css` 用现有的离线 Tailwind CLI 流程重新生成。

### 1. 布局加宽

`<main>` 的 `max-w-2xl`（672px）改为 `max-w-4xl`（896px）。仍是单栏居中的 form/card 布局，不做多栏铺满——它是单条记录视图，不是数据网格。

### 2. 结果卡片视觉层次

- 状态徽章按状态区分颜色：`active` 保持绿色；非 active 统一用更醒目的琥珀/红色而非灰色。
- 今日用量、额度已用/总额度改造为高亮统计块（stat tile）：大字号 teal 色数值 + 小字灰色标签，呼应排行榜页的金额高亮风格。
- 卡片内部分区：基础信息（姓名/分组/状态/Key/过期时间）与统计数字区用背景色/分割线区分；图表区域顶部加分割线和小标题，与统计区拉开层次。

### 3. 空状态引导

新增一个虚线边框的占位卡片，默认可见：图标 + "输入你的 Key 或名称，然后点击查询"文案。查询成功后隐藏占位卡片、显示结果卡片（复用现有 `hidden` 切换逻辑）。

### 4. 不变的部分

- 表单校验、loading/error 状态判断逻辑不变。
- 折线图渲染逻辑不变，只调整外层容器样式。
- `leaderboard.html`、`index.html` 本次不动。

## 验证

- `go build ./...` 通过（若涉及 embed 校验测试）。
- 手动在浏览器验证：加宽后无横向溢出；空状态正确显示/隐藏；深色模式下颜色对比正常；query 后卡片正确渲染。
