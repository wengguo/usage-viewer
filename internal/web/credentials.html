Database Connection

Enter the database credentials to connect to Sub2API's PostgreSQL.

Where to find these values

These are the same credentials used by the Sub2API application. Look in:

  • data/config.yaml — database section (host, port, user, password, dbname, sslmode)
  • Docker Compose .env file — POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB
  • Environment variables — DATABASE_HOST, DATABASE_PORT, etc.
